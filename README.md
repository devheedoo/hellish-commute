# 지옥의 출근길

웨이브 예능 **피의 게임X**의 데스매치 「지옥의 출근길」을 웹에서 해볼 수 있게 만든 MVP입니다.
한 화면에서 두 팀이 번갈아 플레이하는 로컬 대전(핫시트) 방식입니다.

## 실행

```bash
npm install
npm run dev        # 개발 서버
npm test           # 게임 로직 단위 테스트 (vitest)
npm run build      # 타입 체크 + 정적 빌드 (dist/)
```

## 게임 규칙

공개된 방송 정보를 바탕으로 정리한 규칙입니다.

- **게임판**: 14×14 정사각형. 움직일 수 있는 **중립 자동차**와 **고정 구조물**이 놓여 있고, 중앙에 팀 자동차의 시작 위치 8곳이 있습니다.
- **배치**: 머니 챌린지 상위 팀이 선공/후공을 정합니다. → 후공 팀이 **선공 팀 자동차 3대**의 위치를 정합니다. → 선공 팀이 **자기 팀 마지막 1대**의 위치를 정합니다. → 남은 4곳에는 후공 팀 자동차 4대가 자동으로 놓입니다.
- **이동**: 번갈아 차례를 진행합니다. 자기 차례에는 **자기 팀 자동차** 또는 **직전 차례에 움직이지 않은 중립 자동차** 하나를 골라 움직입니다. 자동차는 다른 자동차나 구조물에 막히기 전까지 직선으로 이동합니다.
- **탈출 / 승리**: 팀 자동차가 판 가장자리에 닿으면 탈출합니다. 4대 중 **3대를 먼저 탈출시킨 팀**이 승리합니다.
- **출전 / 타임아웃**: 미리 정한 순서대로 팀마다 한 명씩 1:1로 출전하고, 1분이 지나면 다음 주자로 바뀝니다. 출전자는 대기 중인 팀원과 소통할 수 없습니다. 팀마다 한 번 타임아웃을 쓸 수 있고, 타임아웃 중에는 모든 플레이어가 자유롭게 소통할 수 있습니다.

### 방송 정보로 확인하지 못해 임의로 정한 부분

| 항목 | 이 구현의 처리 |
| --- | --- |
| 실제 맵 배치(구조물·중립 차 위치) | 자체 설계한 180° 회전 대칭 맵 (`src/game/board.ts`의 `LAYOUT`) |
| 중립 차가 가장자리에 닿을 때 | 탈출하지 않고 가장자리 칸에 그대로 남아 장애물이 됨 |
| 움직일 수 있는 타일이 없을 때 | 차례를 넘김. 양 팀 모두 움직일 수 없으면 교착(무승부) |
| 1분 주자 교체 | 화면에 출전 순번만 표시. 차례 순서는 그대로 이어짐 |

## 구조

```
src/
  game/            # React에 의존하지 않는 순수 게임 로직
    types.ts       # 상태·액션 타입
    board.ts       # 맵 레이아웃, 상수, 좌표 유틸
    rules.ts       # 미끄러짐 이동(slide), 선택 가능 여부, 합법 수 계산
    reducer.ts     # 배치 → 플레이 → 종료 상태 전이, 시계(TICK), 타임아웃
    game.test.ts
  components/
    Board.tsx      # 14×14 그리드. 차를 선택하면 갈 수 있는 칸(↑↓←→ / EXIT) 표시
    SidePanel.tsx  # 현재 차례, 탈출 현황, 1분 시계, 타임아웃, 기록
    SetupScreen.tsx
  App.tsx          # useReducer + 시계 interval + 방향키 입력
```

게임 상태는 하나의 `reducer`에 모여 있어서, 이후 온라인 대전(서버 권위 상태 동기화), 되돌리기, 리플레이 같은 기능을 붙이기 쉽습니다.

## 조작

- 차를 클릭하면 갈 수 있는 위치가 표시됩니다. 표시된 칸을 클릭하거나 **방향키**를 누르면 이동합니다. `Esc`를 누르면 선택이 취소됩니다.
- 🔒가 붙은 중립 차는 직전 차례에 움직인 차라서 이번 차례에는 고를 수 없습니다.
